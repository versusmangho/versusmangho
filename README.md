# 버망호 도우미

이 프로젝트는 **버망호 매칭 순서를 간편하게 관리**하기 위해 제작된 웹 애플리케이션입니다.  
브라우저의 로컬 스토리지를 사용하여 **새로고침해도 데이터가 유지**되며,  
우선순위 자동 분배, 매칭 로그, 되돌리기 기능을 포함합니다.

**게임 화면을 한 번 연결해 두면 입·퇴장과 끝난 판의 대진이 자동으로 기록됩니다.**
사람은 닉네임이 아니라 게임 안 명패로 구분하므로 이름을 입력할 필요가 없습니다.
(화면 공유는 `localhost`나 `https`에서만 동작합니다 — 아래 실행 방법 참고.)

### 실행

웹: https://versusmangho.github.io/versusmangho/ — **성과 스캔**의 곡 넘기기·업로드는 그 탭의 **도우미 프로그램 받기**(`vmh-helper.exe`, 설치 없음)를 켜 두어야 합니다.

로컬:

```bash
python helper.py
```

그 뒤 브라우저에서 `http://localhost:8777` 을 엽니다. (`helper.py`는 표준 라이브러리만 쓰는 작은 서버입니다 — 설치할 것 없음)
`python -m http.server 8777`로 열어도 되지만, 그러면 **성과 스캔**의 곡 넘기기(키 입력)와 V-ARCHIVE 업로드가 동작하지 않습니다.
파일을 그냥 더블클릭해도 매칭 표는 쓸 수 있지만, 화면 자동 인식과 층수 측정기는 동작하지 않습니다.

## ✨ Features

한 페이지에 탭 여섯 — **매칭 · 층수 측정기 · 티어별 난이도 · 성과 스캔 · 옵션 · 도움말**. 탭을 바꿔도 기록은 그대로 남고, 화면 자동 인식도 계속 돕니다.

- 플레이어 등록/삭제, 두 명을 클릭해 매칭, 신입 우선권·세이프가드
- 매칭 로그 기록 및 “실행취소/되돌리기”
- **게임 화면 자동 인식** — 화면 공유 한 번으로 입·퇴장과 대진 기록 (매칭 탭) + 밴픽 곡 층수 (층수 측정기 탭)
- **로비 복귀 알림** — 대결이 끝나 화면이 로비로 돌아오면 소리나 알림창으로 알려 줍니다 (옵션 탭에서 켜 두었을 때만)
- 이미지 유사도 기반 플레이어 입장/퇴장 분석 (화면 연결을 못 쓸 때의 수동 방식)
- **티어별 난이도** — 패드와 스시를 같은 축에 얹은 표(패드 12 = 스시 2 · 13 = 4 · 14 = 6 · 15 = 8). 칸을 누르면 공지 문구가 복사됩니다.
- **성과 스캔** — 컬렉션 MUSIC DATA 화면을 한 곡씩 넘기며 최고 점수·MAX 콤보를 읽어(자켓으로 곡 식별, 숫자는 글자 모양 비교) V-ARCHIVE에 오른 기록만 올립니다. 애매한 곡은 검토 후 올립니다.
- 전체 초기화 기능
- LocalStorage 기반 데이터 저장
- 클라이언트 기반 — `helper.py`는 파일 서빙과 성과 스캔의 키 입력·업로드 중계만 합니다 (127.0.0.1에서만 열림)

## 🚀 How to Run

### 1. 클론

```bash
git clone https://github.com/versusmangho/versusmangho.git
cd versusmangho
```

위의 **실행**처럼 `python helper.py`(Windows는 `start.bat`)로 띄운 뒤 `http://localhost:8777`을 엽니다.
