        도움말

        버망호 도우미의 모든 설명이 여기 모여 있습니다. 보고 싶은 곳을 누르세요.

        탭 구성

        • 매칭 도우미: 참가자 명단, 우선순위 대기열, 대진 기록을 관리합니다.
        • 층수 측정기: 밴픽 및 선곡 화면을 인식하여 난이도별 층수 정보를 표시합니다.
        • 티어별 난이도: 세부 티어별 출현 난이도 차트를 확인하고 공지 문구를 복사합니다.
        • 성과 스캔: 인게임 컬렉션 점수를 스캔하여 V-ARCHIVE에 업로드합니다.
        • 방장 봇: 봇 계정이 방장이 되면 매칭 1순위에게 방장을 자동 위임합니다.
        • 옵션: 매칭 규칙, 가중치, 화면 공유 대상, 알림을 설정합니다.
        • 상태 유지: 탭을 전환해도 모든 데이터와 백그라운드 인식이 유지됩니다.

        플레이어 & 매칭

        • 등록: 닉네임을 입력하고 엔터를 누릅니다. 화면 자동 인식 사용 시 인게임 명패로 자동 등록됩니다.
        • 매칭: 대기 목록에서 두 명을 클릭하면 매칭이 기록됩니다. 먼저 클릭한 사람이 원디골로 기록됩니다.
        • 순서: 가중치 점수 순서로 매칭 순위가 부여되며, 보류 중인 인원은 제외됩니다.
        • 정렬: 표 헤더를 클릭하면 해당 열 기준으로 목록이 정렬됩니다.
        • 보류/복귀: 보류 시 매칭에서 제외되며, 복귀 시 보류된 기간만큼 대기 시간이 보정됩니다.
        • 로그: 매치, 입퇴장, 보류 이력을 필터링하여 확인할 수 있습니다.

        🎮 게임 화면 자동 인식

        • 연결 방법: 오른쪽 위 게임 화면 연결을 누르고 DJMAX 게임 창을 선택합니다. 테두리 없는 창 모드를 권장합니다.
        • 화면비: 16:9 및 21:9 화면비를 지원합니다. 21:9는 양옆 여백을 자동 제외합니다.
        • 자동 기록:
          • 입·퇴장: 로비 인원 변동을 감지하여 명단을 실시간 반영합니다.
          • 대진: 라운드 화면 또는 결과 화면을 인식하여 두 플레이어의 매치를 자동 기록합니다.
          • 선곡: 밴픽 및 라운드 화면을 감지하여 밴/플레이 곡을 층수 측정기에 표시합니다.
        • 식별 방식: 닉네임, 명패 이미지, 레벨을 종합 분석하여 플레이어를 식별합니다.
        • 의심 장면: 판정 오류 가능성이 감지된 경우 최근 로비 장면을 수집하며, 의심 장면 버튼에서 zip 파일로 내려받을 수 있습니다.

        🤖 방장 봇

        • 채팅 치환자: {목록}은 대기 순위 및 픽 번호, {봇}은 봇 자리 번호로 치환됩니다.
        • 곡 안내 치환자: {라운드}, {곡}, {패턴}, {층수}, {태그}를 지원합니다. 화면 공유 대상을 둘 다로 설정해야 합니다.
        • 방 다시 만들기: 방 해체 감지 시 설정된 이름과 비밀번호로 방을 다시 생성합니다. {날짜} 치환자를 지원합니다.
        • 작업 중단: 봇을 끄거나 화면 공유 대상을 바꾸면 진행 중인 작업의 다음 입력부터 중단합니다. 다시 켜도 이전 작업을 이어서 누르지 않습니다.
        • 재생성 실패: 화면 확인에 실패하면 10초 간격으로 최대 3회 시도한 뒤 멈춥니다. 생성 키를 이미 보냈다면 다시 누르지 않고 로비가 나타나는지만 확인합니다. 연결과 게임 화면을 확인한 뒤 봇을 껐다 켜서 다시 시도할 수 있습니다.

        🪟 팝업

        • 기능: 항상 위에 표시되는 창으로 매칭 순서와 선곡 정보를 실시간 확인합니다.
        • 표시 항목:
          • 매칭 순서: 우선순위 대기열을 표시하며 상위 2명 및 4판 이상 대기자를 강조합니다.
          • 선곡 정보: 최근 인식된 밴픽 5곡의 난이도, 층수 및 밴/플레이 상태를 표시합니다.
          • 일망호 모드: 선택 곡의 난이도별 층수 표를 표시합니다.
        • 권장 설정: 게임은 창 모드 또는 테두리 없는 창 모드를 사용하고, 화면 공유 시 게임 창을 선택하세요.

        📸 입장/퇴장 분석기 (수동)

        • 사용법: 매칭 도우미 탭에서 로비 스크린샷을 Ctrl+V로 2장 연속 붙여넣어 인원 변동을 분석합니다.
        • 결과: 퇴장은 빨간색, 잔류는 파란색, 입장은 초록색으로 분류됩니다.
        • 주의: 화면 공유 연결 중에는 이 기능이 자동으로 숨겨집니다.

        층수 측정기

        • 수동 캡처: 밴픽 화면에서 캡처 후 Ctrl+V로 붙여넣어 인식할 수 있습니다.
        • 버망호 모드: 5개 밴픽 슬롯의 곡과 층수를 인식합니다. 클릭 시 플레이, 우클릭 시 밴으로 표시됩니다.
        • 일망호 모드: 선택한 곡의 전체 난이도별 층수 표를 제공합니다. 곡 제목이나 별명으로 검색할 수 있습니다.
        • 데이터 복사: Copy 버튼 또는 난이도 칸 클릭 시 곡 및 층수 정보가 클립보드에 복사됩니다.

        패턴 메모

        • 메모 등록: 곡 카드의 ✎ 버튼 또는 난이도 칸 우클릭으로 패턴별 태그를 입력할 수 있습니다.
        • 저장: 메모는 브라우저에 저장되며, 쉼표로 구분하여 여러 태그를 등록할 수 있습니다.
        • 백업: 아래 버튼을 통해 메모 데이터를 JSON 파일로 내보내거나 가져올 수 있습니다.

        티어별 난이도

        • 기능: 세부 티어별 출현 난이도 범위를 시각화하고 공지용 문구를 복사합니다.
        • 복사: 원하는 티어 행을 클릭하면 해당 정보가 클립보드에 복사됩니다.
        • 차트 구분: 파란 막대는 패드, 보라 막대는 SC 난이도를 나타냅니다.

        성과 스캔

        인게임 최고 점수와 MAX 콤보를 스캔하여 V-ARCHIVE에 업로드합니다.

        사전 준비

        1. 도우미 실행: vmh-helper.exe를 실행합니다.
        2. 게임 화면 연결: 게임 화면을 연결하고 테두리 없는 창 모드로 실행합니다.
        3. 계정 설정: V-ARCHIVE DJ 이름을 입력하고 account.txt를 등록합니다.

        스캔 및 업로드 순서

        1. 스캔: 인게임 컬렉션의 MUSIC DATA 첫 곡을 선택하고 스캔 시작을 누릅니다.
        2. 검토: 인식된 점수와 기록을 확인하고 올바른 항목을 선택합니다.
        3. 서버 비교: V-ARCHIVE 기존 기록과 비교하여 갱신된 내역을 확인합니다.
        4. 업로드: 대상 기록을 선택하고 선택한 기록 올리기를 누릅니다.
        도우미 연결 문제 해결
        • 권한 요청: 브라우저에서 로컬 네트워크 접근을 허용하세요.
        • 입력 불가: DJMAX 창이 활성화되어 있는지, 관리자 권한 여부가 일치하는지 확인하세요.
        • 버전 업데이트: 구버전 실행 중인 경우 종료 후 최신 버전을 실행하세요.
        검토 및 업로드 주의사항
        • 중복/상충 기록: 화면과 대조하여 올바른 값 하나만 선택하세요.
        • 서버 미달 기록: 기존 서버 기록보다 낮은 점수는 업로드되지 않습니다.
        • 실패 재시도: 전송 실패 항목을 선택하고 재시도할 수 있습니다.

        기타

        • 자동 저장: 모든 설정과 데이터는 브라우저에 자동 저장됩니다.
        • 실행 취소: Ctrl+Z 또는 되돌리기 버튼으로 이전 상태로 복구할 수 있습니다.
        • 전체 초기화: 브라우저에 저장된 방 데이터를 초기 상태로 리셋합니다.
